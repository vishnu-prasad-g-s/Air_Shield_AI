# Air Shield AI — Original Project Notice

This repository is an adaptation of an existing PM2.5 forecasting project.
The original notebooks and pretrained model files are retained as source
components. They must remain subject to their original copyright, license,
dataset, and model terms.

Air Shield AI additions are contained in the `air_shield_ai/` package and
`dashboard/` directory. The new layer consumes forecast outputs and adds AQI
interpretation, risk summaries, analytics, CLI reporting, and visualization.
